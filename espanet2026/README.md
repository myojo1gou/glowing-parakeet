## 30秒サマリー（この論文が言っていること）

フィンランドは1990年代の10年間で、地方サービス供給を支える財政アーキテクチャを丸ごと組み替えた。1993年の一般財源化改革と緊縮で国庫支出金が縮小した、まさにその時に、1995年のEU加盟が目標6という新しい地域財政の層を挿入した。自治体パネル（452自治体×52機能×1997–99年）が示すのは、**EU層は小さく（国庫支出金総額の1%未満）、プロジェクト形状で、福祉ではなく開発に向かった**こと（中核福祉は9.2%、目標6との関連は経済開発でrate ratio≈7）。そして**自治体台帳レベルでの相殺はほとんど起きていない**（strict apparent complementarity 1.3%、相関+0.05）。

したがって本稿は代替（substitution）を証明しない。**pseudo-complementarity の3次元のうち、①制度的補完性と③行政的変容は支持され、②財政的代替は未決**である。概念の貢献は証拠的ではなく**分析的**——追加性論争で混同される次元を切り分け、各次元に何が必要かを特定する。
