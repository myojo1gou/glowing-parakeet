## 提出前に確認すること

- [ ] 報告題目：2つのファイルにある `【報告題目】` を差し替える
- [ ] 報告日時：プログラムで報告する日と時間帯を確認し、日程表の用務欄に書き足す
- [ ] 新幹線の時刻：日程表の時刻は「頃」で入れた目安なので、予約した便の時刻に直す
- [ ] 丸印：「発表の有」と経路の「自宅」2か所は、9月分の申請書にあった楕円をそのまま使っている。Excelで位置がずれていないか確認する。旅費（学会出張旅費）と授業（支障なし）は、文字で「（○）」と記入した
- [ ] 添付書類：大会の案内とプログラムのPDF（大会ページから入手。注2にある「開催通知書」として使う）
- [ ] 押印：申請者本人、学科長、学部長
- [ ] 提出期限：出張日の2週間前まで。出発日が10月16日なので、**期限は10月2日（金）**
- [ ] 帰ってから：出張報告書を帰任後10日以内（10月28日まで）に提出する
