# 北ヨーロッパ学会 2026年度研究大会 旅程（2026年11月7日・自己負担）

- 会場：東海大学 品川キャンパス（東京都港区高輪2-3-23）。対面とオンラインの併用開催
- 共通論題：「北欧学の新展開」
- 費用：全額自己負担（大学・JFM・GRIPSの旅費は使わない）

## 旅程案：福山から日帰り

| 時刻 | 行程 | 備考 |
|---|---|---|
| 6時台 | 福山駅 発（のぞみ） | 始発付近の便。予約時に時刻を確定 |
| 9時半頃 | 品川駅 着 | 会場までは徒歩約15分（都営浅草線・泉岳寺駅からなら徒歩約5分） |
| 終日 | 研究大会・総会 | 開始・終了時刻はプログラムで確認する（この環境からは学会サイトに接続できなかった） |
| 19時半頃まで | 品川駅 発（のぞみ） | 福山まで乗り継げる最終に近い便。福山着は23時頃 |

- 交通費の目安：福山―品川 のぞみ普通車指定席で片道約1万8千円、往復約3万6千円（概算。予約時に確認）
- 11/7（土）5限の基礎ゼミ（火曜授業の振替日）は対応済みと伺ったので、この旅程に授業は入れていない

## 都内に2泊して、9日の福島調査に東京から合流する案（比較用）

11/7・8に都内で2泊し、9日（月）は東京駅11:36発のやまびこ59号で福島に向かう案です。

- 自己負担：片道約1万8千円＋ホテル2泊。日帰り案（往復約3万6千円）より高くなる可能性が高い
- 福島調査の出張は「東京発」として申請し直す必要がある。旅費の出発地が自宅でなくなるため、先方（JFM・GRIPS）や大学の事務と精算方法を詰めることになる
- 利点：8日（日）を東京で使える。9日の早朝移動（福山7時半頃発）がなくなる

公費と私費の区分がはっきりし、申請書も単純になるので、**日帰り案を推奨**します。福島調査の申請書（`../2026-11_JFM-GRIPS_survey/`）も日帰り案（9日に福山から出発）を前提に作っています。
