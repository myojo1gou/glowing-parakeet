# 調査研究会 訪問調査の出張申請（福島・相模原・大分）

JFM・GRIPS連携プロジェクト「人口減少時代等社会構造変革下における地方財政に関する調査研究会」の2026年度訪問調査のうち、3件について出張申請書を作った。行程は調査研究会の案内（2026年10月）に合わせている。

| 調査 | 出張期間 | 用務先 | 授業 |
|---|---|---|---|
| 福島 | 11/9（月）〜10（火）1泊2日 | 福島県庁 → 郡山市 → 須賀川市 | 支障なし（11/9 月3・4限、11/10 火5限はオンデマンドで実施） |
| 相模原 | 11/13（金）日帰り | 相模原市役所（15時〜17時） | 支障なし |
| 大分 | 11/15（日）〜17（火）2泊3日（15日に前泊） | 大分県庁 → 杵築市 → 別府市 | 支障なし（11/16 月3・4限はオンデマンドで実施） |

共通の記入内容：旅費の出途は先方負担（JFM・GRIPS）、発表は「無」、経路は自宅 ― 会場 ― 自宅、申請日は令和8年10月24日。様式は5月の日本地方財政学会分の申請書を使った。

## 行程で案内と変えたところ

- 福島：福山を7時半頃に出て東京駅11:36発のやまびこ59号に乗る。帰りは郡山16:38発のやまびこ216号で東京に出て、東京からのぞみで福山に22時頃に着く
- 相模原：案内は新宿経由だが、福山から行くので新横浜からJR横浜線で相模原に入る経路にした。帰りも新横浜からのぞみで、福山着は21時半頃
- 大分：15日（日）は小倉で特急ソニックに乗り換えて大分へ。17日は別府市でのヒアリングの後、別府から特急ソニックで小倉に出て、新幹線で福山に15時頃に着く。案内にある大分空港から羽田への便は使わない

## 提出前に確認すること

- [ ] **オンデマンド授業：** 3件とも授業欄は「支障なし」とした。重なる回（11/9・11/16の月3・4限、11/10の火5限）の教材を、配信日までに用意しておく
- [ ] **楕円の位置：** 旅費の楕円は「学会出張旅費」の位置から「先方負担」の位置に動かした。文字の幅から計算した位置なので、Excelで開いて重なりを確認する。授業欄の楕円は3件とも「支障なし」に付けている
- [ ] **大分の出発地：** 11/14（土）19時から洲本で「島留学」があるので、洲本から直接大分に向かう場合は、日程表の15日の出発地と、申請書の経路を書き換える
- [ ] **列車の時刻：** 「頃」と書いたところは目安なので、予約した便の時刻に直す
- [ ] **添付：** 調査研究会の訪問調査の案内（このメール）を開催通知書として付ける
- [ ] **提出期限：** 出張日の2週間前まで。福島は10月26日（月）、相模原は10月30日（金）、大分は11月1日（日）なので、3件まとめて10月26日までに出す
