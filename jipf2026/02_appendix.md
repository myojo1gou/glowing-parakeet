## A-2. 命題ごとの識別上の注意と、反証時の修正

本体§6.1の命題表を補う。点検で見つかった設計上の欠陥（P1の機械的相関、P4の回帰不連続、P6の判定保留）は、ここで直してある。

**P1**
- 注意
  - 主結果変数から国内共同負担を除くと、EUプログラムの開始時に国の財源の一部が共同負担に付け替えられるだけで、負の関係が機械的に出る。そのため、共同負担を含む総額を主結果変数とし、内訳を併記する。
  - 年次の全国系列は約35観測しかなく、2007年のプログラム切替え、2009年のショック、PARAS改革と区別しにくい。地域連合単位の系列が得られるかを先に確かめる。
  - EU配分は、一人当たりGDPで決まる地域区分に依存する。そのため需要と相関する（Knight 2002の問題）。
  - Vehkasalo (2018) の2007年の区域移管は郵便番号区域単位の変動で、地域連合単位の予算を識別するには小さすぎる。
  - 1990年代の地域開発財源は、各省（KTM、SM、MMM）と、1997年以降はTEセンターを通じて配分された。地域連合別の系列があるかは不明。
  - カイヌー行政実験（2005〜12年）と、2011年の東ウーシマー統合を処理する必要がある。
- 追加性の拘束の期間区分（照合要）
  - 1995〜99年：目標6は目標1に準じて検証対象だった可能性がある。
  - 2000〜06年：1260/1999第11条により、東部・北部の目標1地域が対象だった可能性がある。
  - 2007〜13年：1083/2006第15条は収斂目標だけを対象とし、フィンランドには該当地域がなかった可能性がある。
  - 2014〜20年：1303/2013第95条の15%基準により、実質的に対象外だった可能性がある。15%未満を適用外とする段落は、参照したミラーで欠落していた。
  - 2021〜27年：規定そのものが削除された。
- 反証時の修正
  - (b)が成り立つ場合：上方財源は国内移転と同じ平面にあるとし、上方と側方の区別を弱める。
  - (a)が成り立つ場合：EU構造基金論文の「見せかけの補完性」を一般化する主張を取り下げる。

**P2**
- 注意
  - 2012〜15年はプログラム期の切替えと重なる。重なる出来事は次のとおり。
    - 2007〜13年期の閉鎖とn+2
    - 2014〜20年期の立上げの遅れ
    - 地域別5本から全国1本への統合
    - 東部のphasing-in終了
  - このため、年次の全国系列では判定しない。
  - 2015年改革の変動は、33a条の経過調整（2015〜19年）で薄まる。第一段階の強さを先に確かめる。
  - CRII+による100%負担をフィンランドが選んだか（要確認）で、2020/21会計年度を対照期間に使えるかが決まる。
- 反証時の修正：EU資金の利用は国内財政の逼迫から独立しているとし、規律と救済が同じ規則に並ぶ点は条文レベルの記述にとどめる。

**P3**
- 注意
  - 会社化の時期は財政ストレスに対して内生的でありうる（Andrews et al. 2020）。626/2013で強制された群（期限2014年12月31日）と、自発的に会社化した群を分ける。
  - 強制群は自治体単位ではなく事業単位で定義する。配電・水道は第126条第2項第5号で義務の対象外なので、強制の対象になりうるのは発電・小売など競争市場の事業と、個別判断となる地域熱供給である。2024年のタンペレの水道会社化は自発的な会社化にあたる。配電の法的分離は電力市場法による別の要因として扱う（条文と閾値は要照合）。
  - 法人税の流出は、自治体配分の帰属分から、税収ベース調整（平均未満の自治体は差額の90%を加算、平均超の自治体は超過分の10%を減算）による相殺を差し引いた純額で測る（618/2021第26条、要照合）。
  - すでに会社化していた自治体（トゥルク、タンペレ、ヴァンター）を対照にすると、段階的DiDが負の重みで歪む（Goodman-Bacon 2021、要確認）。
  - Vantaan Energiaはヴァンター60%・ヘルシンキ40%の共同所有なので、持分で按分する。
  - 2015年の統計内容の変更は、決算書で接続する。
- 反証時の修正：減少が法人税の流出だけで説明できるなら、会社化の効果は税制の効果に還元される。その場合「決定の場の移動」という主張は弱める。

**P4**
- 注意
  - 営業利益を当期企業所得の代理にすると、特別損益や持分法利益がある年にESA 4.56の判定とずれる。
  - 第118条第3項の数値基準（連結の年間キャッシュ余剰、一人当たり借入、相対債務比率、累積赤字）は kuntakonserni の連結値で計算される。グループ内の配当や特別配当は連結で消去されるので、この基準を動かさない。しかもP4の仮説（基準を避けるためのストック取崩し）は走行変数の操作そのものであり、回帰不連続の前提を壊す。そこで回帰不連続は使わず、第110条第3項の補填期限までの残り年数と単体赤字額を使ったイベントスタディ、および単体収支と連結収支の乖離の分析で検証する。
  - 単体への引出しが効くのは、第118条第2項（第110条第3項の補填に失敗した場合）の側である。KHO 2016:187（Rääkkylä）が典型例になる。
  - 2020〜21年はプラセボ期間ではなく、処置の符号が逆になる期間として扱う。
- 反証時の修正：引出しは企業側の要因（投資周期、所有戦略）で決まっていたとし、吸収の質の議論は記述にとどめる。

**P5**
- 注意
  - 移転額と税率は同時に決まる（Deno and Mehay 1988）。
  - 操作変数の候補（Nord Pool価格×発電容量、配電規制の変更×配電網の保有）は、除外制約が疑わしい。電力価格は地域の課税所得、法人税配分、自治体自身のエネルギー費に直接効くからである。
  - 1990年代分の自治体×年パネルはまだ構築されていない。
  - 事前の反証候補として次の二つを明示する。本人の未公表の予備分析と、Bergh et al. (2022) のスウェーデンの結果（企業依存と高税率が関連）。
- 反証時の修正
  - (a)の場合：要旨の税率抑制命題を撤回する。企業収益は「税率を抑えなかった非租税財源」として、限界租税価格の予測と照合する。
  - (b)の場合：連結範囲の移動仮説を棄却し、金額と法人税による説明を採る。

**P6**
- 注意
  - 熱供給・発電だけを持つ小規模会社を対照にすると、規模も事業構成も違いすぎる。そこで配電を保有する自治体の間で、影響度の差を使う。
  - 2021年8月の改正の直後に2022年の価格ショックが来ている。「ショックを分離できなければ判定を保留する」と広く書くと、実際には保留の条件が満たされて命題が反証されなくなる。保留は、送電損失の購入費が許容費用を超えた事業者だけに限り、その基準を事前に付表で固定する。
  - 2024〜31年の監督方法をめぐる市場裁判所の判断（2025年11月21日、事業者の不服申立てを棄却）について、最高行政裁判所への上訴の有無を確認する。
- 反証時の修正：規制は上限を決めるが、所有者が他事業の利益で配当を維持したと読む。統制主体の軸を、事業別から企業グループ単位に改める。

**P7**
- 注意：公表されている情報に限りがある。統計的推定ではなく、構造化比較として位置づける。
- 反証時の修正：双方向性の議論を、平時の上向きの流れだけに縮める。

**P8**
- 注意
  - EU適格性は地域単位で決まるので、類型と地域がほぼ一致してしまう（共線）。
  - 処置は歴史的に選ばれた連続量であり、周辺部の小規模自治体の人口減少や財政力と交絡する。
  - 2009年の合併を処理する必要がある。
- 反証時の修正
  - 正の相関が出た場合：補完は自治体の内部で生じると改める。
  - 類型間で差がない場合：二財源はどちらも調整に効かなかったと結論する。

## A-3. 識別上の共通の脅威（付表4の原案）

| 脅威 | 影響する命題 | 対処 |
|---|---|---|
| 大規模エネルギー企業を持つ自治体が十数程度しかない | P3〜P7 | 事例比較、wild cluster bootstrap、効果の上限を示す |
| 会社化時期の内生性 | P3、P5 | 強制群と自発群の区別、事前トレンドの確認 |
| 2015年の自治体財務統計の内容変更 | P3〜P5 | 決算書で接続する |
| 2015年改革の33a条経過調整 | P2 | 第一段階の強さを事前に確認する |
| 2021年の規制変更と2022年の価格ショックの重なり | P6、P7 | 用量反応型の設計。判定保留の条件を事前に書く |
| EU支払のプログラム期ライフサイクル | P1、P2 | プログラム年×地域の固定効果 |
| 電力価格の直接効果による除外制約の崩れ | P5、P6 | 操作変数は補助にとどめる |
| 共同所有による処置の干渉（Vantaan Energia） | P3、P5 | 持分で按分する |
| 2009年の合併、2023年の体制転換 | 全般 | 合併後の境界で再集計する。標本は2021〜22年で切る |
| 比率を被説明変数にすると、分母が処置で動く | 全般 | 人口当たり実質の水準を主にする |

## A-5. 想定される質問と応答方針

AIによる模擬査読（3つの立場）で出た質問を整理したもの。実際の討論者の質問ではない。

1. **配当は自治体自身の富の引出しにすぎないのでは。EU補助金と同じ概念にする根拠は何か。**
   → その点は認める。配当を「外部からの財源」とは扱わない。正常収益・超過収益・元本取崩しに分け、連結した異時点間の予算制約の上に置く。二財源を束ねる根拠は資金の出所ではない。上限の決まり方と、限界租税価格が1を下回る条件の狭さである（第2章2.1、第3章3.4）。
2. **GFSMの「国際機関からの補助金」と「財産所得」の組合せと何が違うのか。**
   → 範囲がほぼ重なることは認める。新しいのは分類ではなく、決まり方と規律の比較である。この枠組みでないと説明しにくい観察として、2012〜19年に平均税率が上がり、二財源がそれを抑えなかったことを挙げる（P1・P5が支持された場合）。
3. **経常収入の数%の財源のために理論を組むのはなぜか。**
   → 表1で先に数字を示す。集計で見れば周辺的だと認めたうえで、大都市への集中を示し、二財源が緩衝になったか否かを判定する条件を理論の側で先に示す。
4. **EUは財政学上の上位政府と言えるのか。**
   → EUは課税権をほとんど持たず、財源の大半はGNI拠出である。自己財源決定には加盟国の憲法上の手続による承認が要る（TFEU第311条、要照合）。そこで「配分規則は上から決めるが、財源は加盟国の拠出に依存する超国家の財政主体」として扱う。純拠出国では受取の一部が自国拠出の還流であることも明記する。
5. **EU資金の受益者の多くは自治体以外ではないか。**
   → その通りである。自治体の受取と自治体の共同負担を分けて測る（P2）。自治体を共同負担者として扱うこと自体が、本稿の論点の一つになる。
6. **上限が限界外なら価格効果は生じないのでは。**
   → 価格効果は前提にしない。価格が効く条件を限定し、上限率の期間変化で確かめる。
7. **正常収益と超過収益をどう分けるのか。地域熱に価格規制はあるのか。**
   → 配電はWACC基準で分ける。地域熱には事前規制がなく（要確認）、料金転嫁が最も起きやすい事業として別扱いにする（表2b）。
8. **配当は内生変数だが、外生変動は何か。**
   → 使うのは三つ。会社化時期（強制群と自発群）、2021年規制改正の影響度、第118条の閾値である。電力価格系の操作変数は補助にとどめる。
9. **税率の上昇は Marattin et al. (2022) の pass-through で説明がつくのでは。**
   → 税率上昇そのものはそれで説明できる。本稿が加えるのは、非租税財源がその転嫁を和らげたか、和らげなかったならなぜか、という点である。
10. **EU支払の変動は、プログラム期のライフサイクルで説明できるのでは。**
    → 年次の全国系列では判定しない。同じプログラム年の中で自治体を比べる。
11. **三つの局面は比較なのか、事例の羅列なのか。**
    → 統制された比較ではなく、枠組みの適用例である。フィンランド固有の組合せを見分けるため、スウェーデンとノルウェーを影の事例に置く。
12. **レジリエンスを程度として扱うなら、どちらがよりレジリエントかをどう決めるのか。**
    → 三分類の判定規則で決める（§5.4）。
13. **要旨の税率抑制の主張は撤回するのか。**
    → 事実命題としては撤回し、P5の仮説に改める。本人の未公表の予備分析を、事前の反証候補として示す。
14. **配当の目標を予算で決めているなら、「予算の外」の財源ではないのでは。**
    → 同意する。定義を、上限は外部で決まり、率は所有者が決める、という形に分けた（所有者課税）。
15. **会社化後の減少のうち、どれだけが法人税の流出なのか。**
    → P3で分解して示す。
16. **日本にも納付金や収益事業収入がある。「傍流」と言う根拠は何か。**
    → その存在は認める。主張を「国の財政再建の伝達と結びつけた歳入論の枠組みがない」に限定し、教科書の章立てで示す。
17. **既出のEU論文や2024年の大会報告と何が違うのか。**
    → 違いは三点。企業部門と連結範囲の導入、ESAによる吸収の判定、日本の制度の読み直しである。EUの実証は自己引用で済ませる。
18. **どの命題が反証されたら枠組みを捨てるのか。**
    → 二つに分けて答える。中心命題は、削減影響度の大きい自治体ほど二財源の純受取が増え、それが負担移転を伴わずにサービス維持に寄与した場合に撤回する。上方と側方の区別は、P1が反証条件(b)で反証され、かつP3が反証された場合に撤回する（本体§6.2）。
19. **RRFのような超国家補助金をなぜ扱わないのか。**
    → 扱わないのではなく、対照類型として置く。RRFはEU借入を財源とし、共同負担を伴わず、達成度に連動し、国の予算を経由する。結束政策型との違いが、共同負担と償還払いの効き方をかえって浮かび上がらせる（本体§5.2）。
20. **ノルウェーを「EU非加盟」の影の事例にするのは適切か。**
    → ノルウェーはEEA加盟国として国家補助規則（EFTA監視機関）とEU電力市場指令の適用を受けるので、側方の規律はノルウェーにも及ぶ。構造基金の受益資格はなく、EEAグラントの拠出国である。このため「上方の財源はないが側方の規律はある」事例として置く。
21. **Streeckを退けるのは読み違いではないか。**
    → 退けない。consolidation state は市場アクセスの喪失ではなく、財政協定以後の財政再建規律の制度化を指す。869/2012と1440/2025はその国内実装なので、第1章1.4の歴史的文脈として使う。骨格にしないのは、本稿の分析単位が地方の歳入だからである。
