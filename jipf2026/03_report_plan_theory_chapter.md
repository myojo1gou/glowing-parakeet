# 学会報告版の構成案：理論章の草稿として、データは「結果が出そうなところまで」見せる

作成日：2026年9月30日
目的：報告論文は査読誌に投稿しない。博士論文の理論章について、討論者とフロアから意見を得ることが目的である。構成も分量も、この目的に合わせる。
位置づけ：`01_chapter_structure.md`（投稿論文を想定した版）を、博士論文の理論章の草稿として報告する形に組み替えたもの。01の§3.2〜3.4（投稿版の分量配分・題目案）は本案で無効になる。枠組み（01の§5）と命題（01の§6）は本案で修正した部分を除き有効。
企業側の実証は、別途作成済みの原稿（機能別経常収支統計620とliikelaitos決算、1993–2014年。以下「企業側論文」）を参照する。同論文の数値は本ファイルには転記しない。

---

## 1. 設計の原則

報告は理論章の草稿であり、実証論文の要約ではない。データを見せる目的は、枠組みが空論でないこと、つまり枠組みが予測するパターンがフィンランドのデータに現れつつあることを示すことにある。

見せる範囲は次の規則で決める。

| 見せる | 見せない |
|---|---|
| 分布、規模、集中度 | 回帰の主結果としての係数表 |
| 方向を示す点推定（表の一列） | 標準誤差、p値、信頼区間（脚注に一つだけ） |
| 枠組みが予測する対比（直営／liikelaitos／会社） | 感度分析、頑健性、除外標本 |
| 会計境界がどこで切れるかを示す図 | 会計上の控除計算（H2型） |
| 事例の異質性を示す一覧（会社化の8自治体） | 個別自治体の決算数値の羅列 |

理由は三つある。第一に、係数と精度を出せば、討論は実証設計の批判に向かい、理論章への意見が得られない。報告の目的が意見聴取である以上、これが最大の理由になる。第二に、企業側論文は査読誌に出す原稿であり、報告論文で主要結果を先に配布する必要がない。第三に、「結果が出そうだ」という印象は、係数の有意性ではなく、パターンの一貫性から生まれる。

分量は、理論70%、データ提示25%、結び5%を目安にする。2万字なら6節は約4,000字と図表5点。

1節に、次の趣旨の一文を置く。「本報告は博士論文の理論章の草稿であり、6節の観察は枠組みの妥当性を見るための予備的なものである。識別と検定は実証章に委ねる。本報告では、とくに§2.1に挙げる点について意見を求めたい。」討論者がこの線を越えて実証設計を問う場合、この一文に戻る。

### 2.1 聴衆から引き出したい意見

意見を求める点を報告の中で明示しないと、討論は各人の関心に流れる。1節の末尾か7節の直前に「本報告で意見を求めたい点」として次の四つを置き、討論者にも事前に伝える。

| 論点 | 問い | 想定される分岐 |
|---|---|---|
| 傍流の論証 | 二財源が「財政学の外の枠組みか、例外・病理として扱われてきた」という整理は、日本の地方財政論の読者に通るか。教科書・サーベイの一覧表（2節）で足りるか | 「日本には納付金の規定も収益事業収入もある」という反論。歳入区分と地方財政計画が公営企業を普通会計の外に置いている点で応じる |
| 統合概念の立て方 | 「境界外財源」という一つの概念で二財源を束ねる利点は、別々に扱う場合の損失を上回るか。束ねる根拠（EUの二重の規律、税収ベース調整の外、上限の決定権者が外部）は十分か | 「配当は自分の富の引出しにすぎず、補助金と同じ範疇にできない」という反論。所有者課税と配当の三分解で応じるが、ここは意見を聞きたい |
| 組織境界の四段 | 直営／liikelaitos／株式会社／売却という区分は、日本の直営・公営企業会計・第三セクター・民営化に対応させられるか。対応させる価値があるか | 健全化法の連結範囲（公営企業会計は両面、設立法人はリスク側だけ）との対照が使えるか |
| レジリエンスの位置づけ | レジリエンスを定義の中心から外し、評価基準（サービス水準、供給能力、負担の帰属）に下げることで、題目の「理論的再構成」として成り立つか。それとも概念を捨てて別の題にすべきか | 「財政社会学の側にもレジリエンスの語がある（Musgrave 1992）」で守るか、捨てるか |

四つのうち、本人が最も迷っている点を一つ選び、7節でその点を「開かれた問題」として書く。迷いを隠した報告には意見が付かない。

## 3. 6節の設計：五つの提示物

### 3.1 観測範囲は会計境界で決まる（図1）

- **内容**：直営（機能別統計の620両建て計上）、liikelaitos（同一法人、独立の決算、機能別統計の外）、株式会社（単体の外、連結の内）、売却（連結の外）の四段を横軸に置き、それぞれがどの統計（ktt016、ktt015、連結決算、なし）に現れるかを示す図。下段に、620計上自治体数とliikelaitos観測自治体数の推移（1993–2014年）を重ねる。
- **言うこと**：機能別統計だけでは自治体所有エネルギー事業の大半を捉えられない（企業側論文の結合表：liikelaitos観測のうち620両建てに含まれない割合）。2015年の会社化で、株式会社は自治体統計から消える。測定の範囲が会計境界で決まるからこそ、境界を軸にした枠組みが要る。
- **言わないこと**：計上数の減少を事業の減少と読まない（企業側論文の注意書きをそのまま使う）。
- **出所**：企業側論文の図1と結合表。

### 3.2 規模と集中（表A）

- **内容**：企業側は、liikelaitosの売上高・営業余剰・所有者への支払（自治体への支払利息＋基本資本補償）の中央値と、Helsinkiおよび上位3自治体の売上シェア。EU側は、EU分（ERDF＋ESF）の年平均と、2012年単年の基礎サービス国庫交付金削減額の対比、自治体の共同負担の位置づけ。
- **言うこと**：どちらも集計では周辺的で、企業側は大都市に集中している。だからこそ「なぜ緩衝にならないか」ではなく「どの条件で緩衝になるか」を理論の側で先に決める必要がある。
- **言わないこと**：単年の削減額とプログラム期の年平均を同じ性質の数字として比べない（規模の上限としての対比と注記）。
- **出所**：企業側論文の表3、01の§2.3の数値（要照合分は照合後に）。

### 3.3 枠組みが予測する三つのパターン（表B、図2、表C）

**表B　埋め込みの勾配**

| 組織境界 | 地方所得税率との関連（点推定） | 状態 |
|---|---|---|
| 直営（620両建て計上） | 負 | 企業側論文の表5 |
| liikelaitos | ゼロ近傍 | 同上 |
| 株式会社 | — | 検証中（2015年以降、配当系列） |

- **言うこと**：剰余が自治体予算に直接現れるほど、税率との関連が強い。会計境界を一段外に出ると、関連が消える。これは4節の「決定の場」の議論が予測するとおりの並びである。
- **言わないこと**：減税効果とは呼ばない。条件付き相関と明記し、標準誤差は脚注に一行。株式会社の行を空欄で見せることが、「結果が出そうなところ」の見せ方になる。

**図2　財政ストレスと所有者への支払**

- **内容**：liikelaitosから自治体本体への支払（一人当たり）を、自治体本体の減価償却前収支余剰（vuosikate）の水準で層別した箱ひげ図、または前年の収支余剰との散布図。
- **言うこと**：本体の財政が苦しい自治体ほど支払が大きい傾向がある。これは「所有者課税の率は所有者が決める」という4節の定式化と、作業仮説H4（ストレス下で引出しが強まる）の手がかりになる。
- **言わないこと**：支払が財政を悪化させるという因果の読み。企業側論文の回帰係数（負）は本報告では出さず、記述的な対比だけにする。標本が小さいことは本文で書く。

**表C　会社化は単一の処置ではない**

- **内容**：2014年にliikelaitosを持っていた自治体の、その後の移行の類型。新会社への移管、既存会社群への統合、事業売却、残存の四つに分け、自治体名と時期を示す（企業側論文の表8の要約。売上高の数値は出さない）。
- **言うこと**：「2015年に会社化した」という一つの出来事ではない。境界の移動には、単体の外へ出る移動と、連結の外へ出る移動（売却）が混在する。四段の境界を分ける理由がここにある。
- **言わないこと**：会社化率の数値。全国の会社化を代表する表ではない。

### 3.4 EU側：分母で見え方が変わる（表D）と、自治体の帳簿の外にある流れ

EU側は、機能555（産業・経済振興）に記帳されたEU原資受取を、1997–1999年の本土433自治体について分析した別稿（以下「EU側分析」）から一つの表を作る。

- **内容**：同じEU原資受取を、三つの分母で見た比率。自治体全体の経常＋投資支出、機能555の支出、同機能で観測される補助受取（国庫＋EU）。行は全自治体、財政規模下位四分位、目標6、目標6かつ小規模の四集団。右端に受取経験のある自治体の割合。
- **言うこと**：自治体全体では小数点以下の比率でも、地域開発部門の支出に対しては数%、観測される補助受取に対しては2〜4割に相当する。受取は不均一で、小規模自治体の多くは全期ゼロ、受取があった自治体の約半数は1年だけ。財政規模に対する弾性は全体では比例配分（1）を下回り、小規模側に相対的に厚い。目標6の内側では比例配分と区別できない。
- **言わないこと**：弾性の区間・p値は脚注。「国内財源の代替」「追加性」はこの分析では判定しない（EU側の実証章と既出論文の仕事）。全額を構造基金の確定支払とは呼ばず、「EU原資会計上の受取」と書く。
- **事例を一つ**：Enontekiö。自治体の555受取は3年間ゼロだが、統計局の1997年企業支援統計にはEU共同融資の交付が記録されている。企業向けの資金は自治体の帳簿を通らない。
- **出所**：EU側分析の§2表、§3受取年数、§4主仕様の点推定、§5。

この表の役割は、企業側の図1と対になることである。企業側では会社化によって事業が自治体統計の外に出た。EU側では、そもそも資金の多くが自治体の外（企業、開発会社、地域評議会）を流れている。どちらの財源も、自治体会計という窓からは一部しか見えない。

**図3（任意）　二財源の分布は重ならない**：EU側は財政規模四分位別のU/Xの分布（1997–99年）、企業側は財政規模別のliikelaitos売上の分布（2002–14年）を左右に並べる。時期が違うので統計的な対応ではなく、作業仮説H6（二財源は別々の自治体群に偏る）の出発点として置く。時期の不一致は本文で明記する。

### 3.5 6節の書き方

- 各提示物の前に、それが5節のどの属性・どの境界に対応するかを一文で書く。データが枠組みの図解になるように並べる。
- 「予備的観察」「条件付き相関」「検証中」を各提示物に付ける。付けない箇所は作らない。
- 6節の背骨は「境界」であって「危機の吸収」ではない。EU側は1997–99年、企業側は2002–14年で、2012–19年の削減局面を両財源で同時に観察したデータはまだない。危機の伝達と吸収は作業仮説にとどめ、6節では扱わないと最初に書く。
- 6節の最後に、観察を四つに要約し、7節の作業仮説へ渡す。要約は「観測範囲は会計境界で決まる（両側）」「規模の見え方は分母で決まる（両側）」「埋め込みが浅いほど税率との関連が消える（企業側）」「引出しは所有者の財政状態に応じて動く（企業側）」。

## 4. 7節：作業仮説の修正

企業側論文の結果を受けて、01の§6の命題のうち、企業側の三つを次のように書き直す。

| 仮説 | 修正後 | この報告で見せる部分 | 実証章に残る部分 |
|---|---|---|---|
| H3 | 会社化は本体への移転の水準と形（基本資本補償・利子→配当・資本返還・保証料）を変える | 表C（移行の異質性） | 2015年以降の系列、法人税の純流出の調整 |
| H4 | 本体の財政が苦しいほど、当期利益を超える引出し（元本取崩し）が増える | 図2（liikelaitos期の支払と本体財政の関係） | 会社期の特別配当・資本返還・持分売却 |
| H5 | 剰余が税率に現れる度合いは、会計への埋め込みが浅いほど下がる（直営＞liikelaitos＞株式会社） | 表B（最初の二段） | 株式会社の三段目 |

EU側の二つ（01のP1・P2）は次のように扱う。

| 仮説 | 修正後 | この報告で見せる部分 | 実証章に残る部分 |
|---|---|---|---|
| H1 | EU資金は国庫交付金を代替せず、代替は国の裁量的な地域開発財源に限られる | 見せない（既出のEU論文を引く） | 追加性体制ごとの代替係数 |
| H2 | 共同負担と立替の制約は、参加（受取の有無）に効き、参加した自治体の受取の厚さには効かない | 表Dの二つの方向：受取の発生は大きい自治体ほど起こりやすく、受取額の弾性は小規模側に厚い | 削減影響度・流動性と共同負担額のパネル |
| H6 | 二財源は自治体間で補い合うのではなく、別々の自治体群に偏る | 図3（時期不一致つき） | 同一期間の自治体別データで再確認 |

概念の修正は三つ。

- **観測単位を二つに分ける**：自治体という組織と、自治体の領域。EU資金の多くは領域内の企業・開発会社・地域評議会に流れ、自治体の帳簿を通らない。企業収益は会社化によって組織の外に出るが、領域の中には残る。境界外財源の「境界」は、まず組織の境界であり、領域の境界ではない。この区別は5節の五属性のうち「最終負担者」と「受益範囲」（Olsonの財政的等価性）に接続する。

- **組織境界を四段にする**：直営（機能別会計の内側）→ liikelaitos（同一法人、独立決算）→ 株式会社（単体の外、連結の内）→ 売却（連結の外）。企業側論文が最初の二段を測り、会社化を「境界内から境界外への移動」として捉える。
- **所有者課税のliikelaitos期の対応**：基本資本補償は議会が率を決める正常収益、自治体への支払利息は融資の対価。超過収益と元本取崩しに当たる項目がliikelaitos期の制度にほぼ存在しないこと自体が、会社化で何が可能になったかを示す。

## 5. 想定される討論と応答

討論を理論に向けるための応答方針。実証設計への質問には短く答え、§2.1の論点に引き戻す。

1. **「係数の標準誤差は」** → 脚注の一つを示し、感度分析は実証章と別稿にあると答える。本報告の目的は枠組みの妥当性の予備的確認であり、識別は行っていない。
2. **「liikelaitosで税率との関連がないなら、企業収益は財政を支えていないのでは」** → 支えていないのではなく、支え方が予算に現れないと読む。埋め込みの勾配はそのための概念である。
3. **「H1（部門収支と収支余剰の1対1）はなぜ出さないのか」** → 収支余剰が部門収支を構成要素として含むため、1に近い値は定義から出る。理論章で使う結果ではない。
4. **「EU側の証拠が薄い」** → 既出のEU論文の結果を自己引用で示し、本報告の貢献は二財源を同じ枠に載せることにあると答える。
5. **「2015年以降はどうなるのか」** → 表Bの空欄がそれである。配当・利子・保証・売却の系列を接続する作業が実証章の中心になる。
