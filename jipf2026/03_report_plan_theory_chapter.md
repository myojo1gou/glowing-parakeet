# 学会報告版の構成案：博士論文のミニチュア版として、データは「結果が出そうなところまで」見せる

作成日：2026年9月30日（10月1日改訂）
目的：報告論文は査読誌に投稿しない。博士論文の理論枠組みと全体の構成について、討論者とフロアから意見を得ることが目的である。
形：博士論文のミニチュア版。理論章→EU章→企業章→統合→結論の順を縮小して再現し、各実証章は「制度と会計境界／既存研究の扱い／予備的観察／作業仮説」の同じ型で書く。理論が後の章でどう使われるかを聴衆に見せるためである。
位置づけ：`01_chapter_structure.md`（投稿論文を想定した版）の§2（論点整理）、§5（枠組み）、§6（命題）は参照用として残す。同§3.2〜3.4（投稿版の分量・題目）は無効。
参照する分析：企業側（機能別経常収支統計620とliikelaitos決算、1993–2014年。原稿あり）、EU側（機能555のEU原資受取、1997–1999年、本土433自治体。分析あり）、既出のEU構造基金論文。いずれの数値も本ファイルには転記しない。

## 1. 設計の原則

### 1.1 データの見せ方

**方向と規模は見せ、精度は見せない。** 点推定と分布は出す。標準誤差・感度分析・頑健性は別稿に置く。

| 見せる | 見せない |
|---|---|
| 分布、規模、集中度、分母を変えた比率 | 回帰の主結果としての係数表 |
| 方向を示す点推定（表の一列） | 標準誤差、p値、信頼区間（脚注に一つだけ） |
| 枠組みが予測する対比（直営／liikelaitos／会社、参加／厚さ） | 感度分析、頑健性、除外標本 |
| 会計境界がどこで切れるかを示す図 | 会計上の控除計算（H2型） |
| 事例の異質性を示す一覧、事例の一段落 | 個別自治体の決算数値の羅列 |

理由は三つ。第一に、係数と精度を出せば討論は実証設計の批判に向かい、理論と構成への意見が得られない。第二に、企業側論文は査読誌に出す原稿であり、報告で主要結果を先に配布する必要がない。第三に、「結果が出そうだ」という印象は、有意性ではなくパターンの一貫性から生まれる。

### 1.2 ミニチュアとしての規則

- 各実証章は同じ四つの節で書く。①制度と会計境界（この財源はどこに記録され、どこで見えなくなるか）、②既存研究の扱い（財政学の外か、例外・病理としてか）、③予備的観察、④作業仮説と実証章の設計。二つの章を同じ型にすることで、対称性そのものが主張になる。
- 各実証章の③は「境界と観測範囲」を背骨にする。「危機の吸収」は扱わない。EU側は1997–99年、企業側は2002–14年で、2012–19年の削減局面を両財源で同時に観察したデータはまだない。このことは序章で言い切る。
- 終章に博士論文の章構成と進捗の表を置く。どこまで出来ていて、どこが未着手かを見せたほうが、意見は具体的になる。
- 分量は理論35%、実証二章で40%、序章・統合・終章で25%。2万字なら第1章6,000字、第2・3章各4,000字前後。

## 2. 博士論文の主張（序章に置く一段落の文案）

> 国の財政再建が政府間財政関係を通じて地方に伝わるとき、フィンランドの自治体は、国内の租税と政府間移転の外にある二つの財源を持っていた。EU結束政策の資金と、自治体が所有するエネルギー企業からの資金移転である。既存の財政学は、前者を地域政策や多層ガバナンスの問題として、後者を財政錯覚や資源の呪いとして、つまり歳入論の外か例外として扱ってきた。本論文はこの二つを「境界外財源」として政府間財政関係論の正規の範疇に組み込み、両者がどの条件で危機を和らげ、どの条件で負担を利用者・将来年度・他の納税者へ移すのかを、1990年代から2010年代のフィンランドの経験で検討する。本報告はその縮図であり、理論枠組みと、二つの実証章の予備的観察を示す。

### 序章　問いと構成

問い、博論の主張（§2の一段落）、本報告の性格（ミニチュア、予備的観察、識別と検定は実証章）、意見を求めたい点（§5）への予告。「両財源を同時に観察したデータはまだない」をここで書く。

### 第1章　理論枠組み：境界外財源

- 1.1 政府間財政関係論の二つの閉鎖：交付者は国内の上位政府、受領者は一般会計。二財源が財政学の外か例外・病理として扱われてきた経緯。教科書・サーベイでの扱いの一覧表は脚注または付表。
- 1.2 上方の開放：財政主体としてのEU、補完性と追加性、閉鎖型定率補助としての結束政策、三類型（結束政策型・RRF型・REACT-EU型）。
- 1.3 側方の開放：租税国家論とドメイン収入、所有者課税、配当の三分解、liikelaitos期の対応（基本資本補償＝正常収益、支払利息＝融資の対価）。
- 1.4 境界外財源の定義、二軸と五属性（表1）、四段の組織境界と二つの観測単位（図A）。
- 1.5 二財源を束ねる理由：EUの二重の規律、税収ベース調整の外、上限の決定権者が外部。
- 1.6 評価基準としてのレジリエンス：吸収の判定と最終負担者。

01の§5の定義・表を、四段の境界と二つの観測単位に合わせて改訂して使う。

### 第2章　上方の財源：EU結束政策資金と自治体

- 2.1 制度と会計境界：自治体は受益者・事業実施者・共同負担者であり、一般財源の受取主体ではない。資金の多くは企業・開発会社・地域評議会を流れ、自治体の帳簿を通らない。機能555は自治体に入った部分だけを見る窓。
- 2.2 既存研究の扱い：成長・収斂効果（地域経済学）、多層ガバナンス（政治学）、追加性の検定。政府間財政関係の一つの層として扱う研究はない。既出のEU論文の「見せかけの補完性」をここで一般化する。
- 2.3 予備的観察（表D）：同じEU原資受取を、自治体全体の支出、機能555の支出、観測される補助受取の三つの分母で見る。四集団（全自治体、財政規模下位四分位、目標6、目標6かつ小規模）。受取の不均一（多くは全期ゼロ、あっても1年だけ）。財政規模に対する弾性は全体では比例配分を下回り、目標6の内側では区別できない。受取の発生は大きい自治体ほど起こりやすい。Enontekiöの一段落：自治体の受取はゼロだが、企業支援統計にはEU共同融資の交付がある。
- 2.4 作業仮説と実証章：H1（EU資金は国庫交付金を代替せず、代替は国の裁量的な地域開発財源に限られる）、H2（共同負担と立替の制約は参加に効き、参加した自治体の受取の厚さには効かない）。実証章では、追加性体制ごとの代替係数と、削減影響度・流動性と共同負担額のパネル。

数値の表示は§1.1の規則。全額を構造基金の確定支払とは呼ばず、「EU原資会計上の受取」で通す。5880・7150にEU分と国内共同負担が混在するかは、勘定科目表で確認してから語を決める。

### 第3章　側方の財源：自治体エネルギー企業と自治体会計

- 3.1 制度と会計境界：直営（機能別統計の内側）→ liikelaitos（同一法人、独立決算、機能別統計の外）→ 株式会社（単体の外、連結の内）→ 売却（連結の外）。2013年改正（626/2013）と2014年末の期限。自然独占は義務の対象外。
- 3.2 既存研究の扱い：DiLorenzo（1982）は公営電力の利益による一般会計補填を「財政錯覚」と読んだ。Borge et al.（2015）は水力収入を「資源の呪い」で読んだ。会社化は公共経営の側で統治と効率の問題として研究された。歳入の範疇として扱う研究はない。
- 3.3 予備的観察：
  - 図1 会計境界と観測範囲：四段の境界がどの統計に現れるか。620計上自治体数とliikelaitos観測数の推移。liikelaitos観測の大半が機能別統計の両建て計上に入らないこと。
  - 表B 埋め込みの勾配：直営は税率と負の関連、liikelaitosはゼロ近傍、株式会社は検証中（空欄で見せる）。減税効果とは呼ばない。
  - 表C 会社化は単一の処置ではない：2014年にliikelaitosを持っていた自治体の移行の類型（新会社への移管、既存会社群への統合、事業売却、残存）。
  - （任意）図2 財政ストレスと所有者への支払：本体の収支余剰の水準で層別した支払の分布。因果ではなく、所有者課税の率を所有者が決めることの手がかり。
- 3.4 作業仮説と実証章：H3（会社化は移転の水準と形を変える）、H4（本体の財政が苦しいほど当期利益を超える引出しが増える）、H5（剰余が税率に現れる度合いは埋め込みが浅いほど下がる：直営＞liikelaitos＞株式会社）。実証章では、2015年以降の配当・利子・保証・売却の系列と、直営／liikelaitos／会社の三群比較。

H1型の結果（部門収支と収支余剰の1対1）は出さない。収支余剰が部門収支を構成要素として含むため、1に近い値は定義から出る。

### 第4章　二財源を同じ枠で見る

- 4.1 境界の対称性：EU側は組織の外・領域の内を流れ、企業側は会社化で組織の外に出るが領域には残る。どちらも自治体会計という窓からは一部しか見えない。境界外財源の「境界」はまず組織の境界である。
- 4.2 規模の見え方は分母で決まる：両側とも、自治体全体に対しては小さく、部門・事業に対しては大きい。
- 4.3 H6（二財源は別々の自治体群に偏る）と、（任意）図3。時期の不一致を明記。
- 4.4 危機の伝達との接続：2012–19年の削減局面で両財源がどう動いたかは作業仮説のまま。国の姿勢（転嫁の局面と吸収の局面）を変数とする設計だけ書く。
- 4.5 日本への含意は一段落：地方公営企業法の二つの向き（第17条の2と第18条第2項）、健全化法の連結範囲の非対称。

### 終章　結論、博士論文の構成、開かれた問題

## 5. 聴衆から引き出したい意見

意見を求める点を報告の中で明示しないと、討論は各人の関心に流れる。序章で予告し、終章で並べ、討論者には事前に送る。

| 論点 | 問い | 想定される分岐 |
|---|---|---|
| 傍流の論証 | 二財源が「財政学の外の枠組みか、例外・病理として扱われてきた」という整理は、日本の地方財政論の読者に通るか | 「日本には納付金の規定も収益事業収入もある」という反論。歳入区分と地方財政計画が公営企業を普通会計の外に置いている点で応じる |
| 統合概念の立て方 | 「境界外財源」で二財源を束ねる利点は、別々に扱う損失を上回るか。束ねる根拠は十分か | 「配当は自分の富の引出しにすぎない」という反論。所有者課税と配当の三分解で応じるが、意見を聞きたい |
| 組織境界の四段と二つの観測単位 | 直営／liikelaitos／株式会社／売却、組織／領域という区分は、日本の直営・公営企業会計・第三セクター・民営化に対応させる価値があるか | 健全化法の連結範囲との対照が使えるか |
| レジリエンスの位置づけ | 評価基準に下げて「理論的再構成」と言えるか。概念を捨てて別の題にすべきか | Musgrave（1992）で守るか、捨てるか |
| 博論の構成 | 二つの実証章を同じ型で対称に置く構成は、読者に通るか。統合章を独立させるべきか | 対称性を主張にするか、EU章を制度史に寄せるか |

## 6. 想定される討論と応答

討論を理論と構成に向けるための方針。実証設計への質問には短く答え、§5の論点に引き戻す。

1. **「係数の標準誤差は」** → 脚注の一つを示し、感度分析は実証章と別稿にあると答える。
2. **「liikelaitosで税率との関連がないなら、企業収益は財政を支えていないのでは」** → 支え方が予算に現れないと読む。埋め込みの勾配はそのための概念。
3. **「EU資金は自治体全体の0.0x%にすぎない」** → 表Dの三つの分母。部門・事業に対しては大きい。局地的な開発財源としての重要性は、全体比率の小ささからは否定できない。
4. **「二つの実証は時期が違う。危機の伝達は検証していないのでは」** → そのとおり。本報告の実証は境界と観測範囲について。危機の伝達は作業仮説で、国の姿勢を変数とする設計を第4章4.4に示した。
5. **「2015年以降はどうなるのか」** → 表Bの空欄がそれである。第6章の仕事。
6. **「H1（1対1）はなぜ出さないのか」** → 定義から出る値であり、理論章で使う結果ではない。
