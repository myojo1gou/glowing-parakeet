# 大野地区インタビュー動画（木戸議員・竹本さん）編集企画一式

撮影済みの2本

- https://youtu.be/2-AvwIqPyfY
- https://youtu.be/a24NbWjA8X4

を、自治体職員・大学の地域連携担当者に向けた「域学連携のメリットとノウハウ」動画（PIVOT TALK型の対談編集）に仕上げるための文書一式です。NPO法人洲本域学連携研究所の「域学連携動画・WEBメディア事業（域学連携のノウハウを全国に！）」の第1〜2弾として位置づけています。

## ファイルと渡す相手

| ファイル | 読む人 | 用途 |
|---|---|---|
| `01_編集企画書.md` | 鈴木（代表理事）、構成を担当する学生 | 結論、論点、構成案（章立て・拾う発言・インサート）、スケジュール、費用、判断事項 |
| `02_編集指示書.md` | 編集者（外注または神戸学院大学の学生） | 納品物、技術仕様、テロップ仕様、修正回数、支払・証憑 |
| `03_素材ログ_手順と記入例.md` / `03_素材ログシート.csv` | ログを取る人（学生・事務局） | 2本の素材を発言単位でタイムコード付きに分解する作業手順と記入用シート |
| `04_公開前チェックリスト.md` | 鈴木、事務局 | 出演者確認、市企画課への共有、公選法・肖像権・事実確認 |
| `05_YouTube公開テキスト案.md` | 公開作業をする人 | タイトル、説明文、チャプター、タグ、サムネ文言、ショート3本の設計 |
| `06_依頼文テンプレート.md` | 鈴木、事務局 | 出演者への公開前確認、市企画課への事前共有、編集者・学生への依頼文 |

## 前提と制約

- この一式を作った環境からはYouTubeに接続できず、2本の動画本体・自動字幕を確認できていません。構成案は「仮説構成」です。`03_素材ログシート.csv` を埋めれば、タイムコード付きの構成台本に確定できます。
- 企画の前提は、Google Drive上の「洲本_域学連携_インタビュー・メディア事業_プレゼン資料」「絆プロジェクト申請案_B案_メディア事業」、および2020年以降の木戸隆一郎議員・洲本市企画課とのメールから取っています。
- 竹本さんの肩書・立場、撮影日、2本の動画がそれぞれ誰のインタビューか（1本ずつか、前後半か）は未確認です。文書中では【要確認】で示しています。

## 作業の順番（最短ルート）

1. YouTube Studioで2本の自動字幕（.srt）をダウンロードし、`03_素材ログシート.csv` に発言単位で記録する（2本で2〜3時間）。
2. ログの「評価A」の合計尺で、1本（15〜20分）にするか前編・後編に分けるかを決める（`01` の2章）。
3. `01` の構成案に発言を当てはめ、タイムコード付きの構成台本にする。
4. `02` と構成台本を編集者に渡す。ラフカットを出演者と市企画課に限定公開で確認してもらう（`04`、`06`）。
5. `05` のテキストで公開。ショート3本はSNSとイキガクEXPOの告知に使う。
