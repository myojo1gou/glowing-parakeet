# 編集企画書：大野地区・木戸隆一郎議員×竹本さん インタビュー

対象素材：https://youtu.be/2-AvwIqPyfY ／ https://youtu.be/a24NbWjA8X4
作成日：2026年10月18日
事業：NPO法人洲本域学連携研究所「域学連携動画・WEBメディア事業 ー域学連携のノウハウを全国に！ー」

---

## 0. 結論

1. **2本の素材を「議員の視点」と「住民の視点」のクロスカットで1本（15〜20分）にまとめ、ショート3本を切り出す。** 評価Aの発言が合計25分を超える場合だけ、前編（メリット編）・後編（受け入れの実務編）に分ける。
2. **PIVOT TALKから借りるのは4点だけ。** 冒頭30〜60秒のハイライト、章カードで区切る章立て、全文字幕ではなく要点テロップ、主張を先に出すタイトル。スタジオの見た目やテンポまで真似る必要はない。視聴者は自治体の企画担当と大学の地域連携担当で、欲しいのは雰囲気ではなく「何が得られ、何が必要で、どこで躓くか」。
3. **最初にやる作業は編集ではなく素材ログ。** YouTube Studioから自動字幕（.srt）を落とし、`03_素材ログシート.csv` に発言単位で記録する。これがないと構成もテロップも外注も始まらない。
4. **議員が出演する動画なので、市政批判・政策主張・会派や選挙に関わる発言は全部切る。** 木戸氏が当法人の顧問である事実は説明欄に書く。公開前に洲本市企画課（高橋さん）にラフカットを共有する。

## 1. 論点整理

### 1.1 この動画がメディア事業の中で担う役割

プレゼン資料（2026年5月）では、年度内にインタビュー動画3〜4本、想定ターゲットは地域住民団体・自治体・大学関係者・各種メディア、期待する広がりは「視察・取材・ツアー等への展開」とされている。絆プロジェクトB案でも、成果物は「視察受入資料、外部連携の入口」と位置づけている。

つまり、この動画の成果は再生回数ではなく、**見た自治体職員や大学教員が洲本に問い合わせてくること**にある。KPIは次の3つに絞る。

| 指標 | 目標（公開後3か月） | 測り方 |
|---|---|---|
| 自治体・大学からの問い合わせ、視察相談 | 3件 | 問い合わせフォーム・メールに「動画を見た」の有無を記録 |
| 10分時点の視聴維持率 | 40%以上 | YouTube Studio アナリティクス |
| 上映・紹介された場の数 | 3回（イキガクEXPO、大学コンソーシアムひょうご神戸関連の場、市企画課の説明資料など） | 事務局で記録 |

### 1.2 誰に、何を持ち帰ってもらうか

| 視聴者 | 見終わったあとに言えるようになってほしいこと |
|---|---|
| 自治体の企画・地域振興担当 | 議会・市役所・地域の三者がどう噛み合ったか。予算と担当者をどう確保したか。 |
| 大学の地域連携センター、ゼミ教員 | 受け入れ側が学生に何を期待し、何に困っているか。最初に誰に連絡すればいいか。 |
| 自治会・まちづくり協議会の役員 | うちの地区でもできそうか。最初の一歩は何か。 |

三者に共通するのは「理念は分かっている。知りたいのは段取りと失敗」という点。章立てはここから逆算する。

### 1.3 PIVOT TALKの要素分解と、今回の翻案

| 要素 | PIVOTの対談動画に共通する作り | 今回の翻案 | 理由 |
|---|---|---|---|
| 冒頭 | 本編の強い発言を30〜60秒に凝縮したハイライトから始め、ロゴが出る | 同じ。3〜5発言、各5〜10秒。最後は「問い」で本編へ渡す | 自治体職員は冒頭1分で見るか決める |
| 出演者紹介 | 名前・肩書を大きくテロップ、短いプロフィール | 名前テロップ＋「大野地区と学生の関わり」を1行で。経歴紹介は長くしない | 肩書より「この人がなぜ語れるのか」が要る |
| 章立て | 3〜5章、章カードで区切る。章題は問いになっている | 4章＋エンディング。章題はすべて疑問形 | 視聴者がチャプターから飛べる |
| テロップ | 全文字幕ではなく要点。キーワードを大きく、数字・固有名詞は必ず文字化 | 同じ。ただし聞き取りにくい箇所だけ全文字幕 | 公民館や屋外収録の可能性があるため |
| インサート | 図解スライドを1〜2枚挟む | 「洲本市の域学連携の体制図（市企画課・NPO・大学・地区）」「大野地区の受け入れの流れ」の2枚 | 言葉だけでは体制が伝わらない |
| 本数 | 前編・後編、各15〜25分 | 原則1本。素材が持つときだけ前後編 | 2本に分けると後編の再生が落ちる。問い合わせ導線は1本の方が強い |
| タイトル | 【　】で主張を先頭に置く | 同じ。ただし煽らない。「〇〇の本音」程度まで | 行政・大学向けに過度な煽りは逆効果 |
| サムネイル | 顔アップ＋大きな文字2行 | 木戸氏と竹本さんの2人の顔＋2行 | 「議員と住民が一緒に語る」が売り |
| 聞き手 | 聞き手が視聴者の疑問を代弁する | 聞き手の質問を「質問テロップ」として画面に出す（聞き手の映像は使わなくてよい） | 1カメ収録でも対談の形になる |
| 終わり | 次回予告、関連動画 | 「視察・相談はこちら」と当法人の連絡先、次の動画の予告 | 成果は問い合わせ |

### 1.4 議員が出演する動画に固有の論点

- 公職選挙法上、選挙期間外に議員が地域活動について語る動画を公開すること自体は問題ない。問題になるのは内容と見え方。**市政批判、政策主張、他の議員・会派・政党への言及、2026年3月の市議選や公約に触れる発言はすべて切る。** ログで「政治」タグを付けて機械的に除外する。
- 木戸氏が当法人の顧問であることは、説明欄に「本動画の出演者である木戸隆一郎氏は当法人の顧問です」と明記する。伏せると、後から「NPOが議員の広報をしている」と言われたときに反論できない。
- 肩書は「洲本市議会議員」のみ。当選回数、所属会派、淡路青年会議所などの経歴は本人に確認してから入れるかどうか決める。
- 域学連携は洲本市企画課が2013年から続けている市の事業でもある（高橋壱さんのメール署名にある「域学連携13年目突入」）。市の名前、市の資料、市が撮影した写真を使う場合は、ラフカット段階で企画課に共有する。公開後に知らせる形は避ける。

### 1.5 素材を見ていない前提で想定しているリスク

| リスク | 起きたときの対処 |
|---|---|
| 2本が別々のインタビューで、質問が揃っていない | クロスカットを諦め、章ごとに主役を決める（例：第1・3章は木戸氏、第2・4章は竹本さん） |
| 1カメ固定でジャンプカットが目立つ | 話者が替わるタイミングで切る。写真・図解のインサートで隠す。1.1〜1.2倍のデジタルズームで変化をつける |
| 公民館の反響、屋外の風音 | DaVinci Resolveのノイズ除去、またはAdobe Podcast Enhance（無料）で処理してから編集 |
| 固有名詞（地名、団体名、人名）の聞き取りミス | ログの「要確認」列に残し、出演者確認のときにまとめて聞く |
| 第三者（住民・学生）の顔が映っている | 使う部分を限定する、ぼかす、または本人に許諾を取る |

## 2. 実務上の判断

### 2.1 本数

デフォルトは1本（15〜20分）＋ショート3本。素材ログを取って、評価Aの発言の合計尺で決める。

| 評価Aの合計尺 | 判断 |
|---|---|
| 12分未満 | 1本（12〜15分）。足りない章は削る |
| 12〜25分 | 1本（15〜20分） |
| 25分以上 | 前編（メリット編）・後編（受け入れの実務編）に分ける |

### 2.2 編集体制

| 案 | 費用の目安 | 納期 | 品質 | 属人化 |
|---|---|---|---|---|
| A. 鈴木が自分で編集 | 0円 | 読めない（他業務と競合） | 内容理解は最良。仕上げは粗くなる | 最悪 |
| B. 神戸学院大学の学生チーム | 謝金1〜3万円＋指導時間 | 読めない。授業期間に左右される | ばらつく | 中 |

**推奨：構成・ログ・テロップ文言はNPO側（鈴木＋学生）、カット編集・テロップ入れ・音声処理は外注（C）。** 理由は3つ。構成は域学連携の文脈が分からないと作れず外注に向かない。作業部分は仕様書があれば誰でもできる。学生に全部任せると納期が読めず、2026年度内3〜4本の計画が崩れる。

学生には「構成案に対する視聴者目線の意見」「ショート動画の切り出し提案」「テロップ文言の案出し」を頼む（プレゼン資料で学生が担うとした「学生目線での魅力の切り取り」「動画・記事・SNSでの見せ方」に当たる）。依頼文は `06` にある。

### 3.2 章ごとの「問い」と、拾うべき発言の型

ログを取る人は、各発言がどの章の「拾う型」に当たるかを `章候補` 列に書く。該当する発言が1つもない章は削る。無理に埋めない。

**第1章 なぜ大野に学生が来たのか**

- 問い：大野地区はどんな地区で、学生が来る前はどういう状況だったのか。最初のきっかけは誰の、どんな一言だったのか。
- 拾う型：人口・世帯・高齢化の具体的な数字や実感。「最初は〇〇だと思っていた」という当初の警戒や期待。木戸氏が市役所（企画課）と地区をつないだ経緯。2020年に京都大学の学生団体と「洲本トライアングル」をやったときの話が出ていれば、連携の始まりとして使える【要確認：この動画で触れているか】。
- 削る判断：きっかけの話がどちらにもなければ、第1章は「大野地区の現状」だけにして2分に縮める。

**第2章 学生が来て、何が変わったか**

- 問い：住民の側で、何が目に見えて変わったか。議員の側から見て、地区・市役所・議会の空気はどう変わったか。学生自身はどう変わったか。
- 拾う型：「〇〇さんが久しぶりに外に出た」「集まりの参加者が増えた」のような固有のエピソード。数字（参加人数、回数、年数）。学生が卒業後も関わっている話。「正直、期待していなかったが」のような転換。
- インサート：活動写真。Driveの「毛利さん撮影の写真※注意事項あり」は使用条件を先に確認する。
- 削る判断：抽象的な「元気になった」しかなければ、エピソードを出演者確認のときに追加で聞き、テロップで補う。

**第3章 受け入れの段取りと、つまずいたこと**

- 問い：学生はどこに泊まり、何を食べ、誰が送迎したのか。費用は誰が持ったのか。市役所との役割分担はどうだったか。うまくいかなかったことは何で、そのときどうしたか。
- 拾う型：宿泊先、食事、移動、保険、謝金、補助金の名前。「最初の年は〇〇で失敗した」。住民の負担感、担当者が固定されてしまう悩み。学生のマナー・時間・連絡の問題と、その対処。
- インサート：体制図（洲本市企画課・当法人・大学・地区の関係）、受け入れの流れ図（打診→事前打合せ→受入→振り返り）。
- この章が動画の価値の中心。自治体・大学の視聴者が最も知りたい部分なので、素材があれば最長にする。
- 注意：補助金名や金額は事実確認してからテロップにする。市の制度名は企画課に確認する。

**第4章 これから始める人へ**

- 問い：続けるために何を仕組みにしたか。担当者が替わっても続くのか。これから始める自治体・大学・地区に、最初の一歩として何を勧めるか。
- 拾う型：「まず〇〇に連絡する」「最初は〇〇人規模で」「議員の役割は〇〇」「大学に求めるのは〇〇」のような具体的な助言。「やらない方がいい」の忠告も価値がある。
- 終わり方：竹本さんの一言で締める（住民の言葉で終わる方が、自治体・大学の視聴者に残る）。

### 3.3 前編・後編に分ける場合

| | 前編（メリット編） | 後編（受け入れの実務編） |
|---|---|---|
| 内容 | 第1章・第2章 | 第3章・第4章 |
| 尺 | 12〜15分 | 12〜15分 |
| ハイライト | 両編とも、その編の本編から作る。前編のハイライトに後編の発言を混ぜない | 同左 |
| エンディング | 後編の予告（後編の最も強い発言を10秒） | 連絡先、視察案内 |
| タイトル | 【学生が来ると地域はどう変わる？】 | 【受け入れの本音】 |

### 3.4 冒頭ハイライトの作り方

1. ログの評価Aから「結論を言っている」「数字がある」「意外性がある」「感情が乗っている」発言を各1つ以上、合計3〜5個選ぶ。
2. 各5〜10秒に切る。文の途中で切らない。
3. 順番は「意外性 → 数字 → 結論 → 感情」。最後の発言のあとに1秒の間を置き、問いテロップ（例：「学生が来ると、地域は本当に変わるのか？」）を出してタイトルへ。
4. ハイライトで使った発言は本編でも使ってよい。ただし本編で再登場するまで3分以上空ける。

### 3.5 クロスカットのルール

- 同じ問いに対する2人の答えを続けて見せるときは、先に住民（竹本さん）、次に議員（木戸氏）。住民の実感を議員が制度側から補足する順が、自治体・大学の視聴者には分かりやすい。
- 1人の発言は原則60秒以内で切り替える。90秒を超える場合はインサートを挟む。
- 2人の意見が食い違う部分があれば切らずに残す。食い違いは「本音」の証拠になり、この動画の信頼性を上げる。

## 4. タイトル・サムネイル・説明文

候補と説明文の全文は `05_YouTube公開テキスト案.md` にある。方針だけここに書く。

- タイトルは「【問い or 主張】地域名・立場・年数（編）」の順。例：【学生が来ると地域はどう変わる？】洲本市大野地区の域学連携を、市議と住民が語る

- 説明欄の冒頭3行で「誰向けか」「何が分かるか」「問い合わせ先」を書く。木戸氏が顧問であることもここに書く。

## 8. 鈴木さんに判断してもらう点

1. **1本か前後編か**：ログ後に2.1の基準で決める。デフォルトは1本。
2. **編集体制**：2.2のハイブリッド（構成はNPO、作業は外注）でよいか。外注先の候補が手元になければ、クラウドソーシング（ランサーズ・ココナラ）で「対談動画 テロップ編集」の実績がある個人に相見積もり3件。
3. **竹本さんの肩書表記**：本人にどう名乗りたいか確認（例：大野地区 ○○会 ○○、大野地区住民）。
4. **市企画課への共有タイミング**：ラフカット段階を推奨。公開直前だと修正が間に合わない。
5. **シリーズ名**：今後3〜4本続けるので、シリーズ名を決めてロゴを作る（例：「イキガクTALK」「洲本・域学連携の現場から」）。この1本目で決めておくと、2本目以降の編集指示が短くなる。
6. **ハイライトの「問い」テロップの文言**：3.1の案「学生が来ると、地域は本当に変わるのか？」でよいか。素材の内容次第で「議員は域学連携で何をするのか？」の方が強い可能性がある。
