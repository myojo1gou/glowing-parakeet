## 4. 構成とカットのルール

1. 構成台本の順番と発言を守る。発言の前後を数秒伸ばす・縮めるのは可。発言の入れ替えや、台本にない発言の追加は担当に確認する。
2. **使わない発言**：市政批判、政策の主張、他の議員・会派・政党への言及、選挙や公約に関する発言、第三者の個人名を挙げた評価、特定企業の宣伝。構成台本では除外済みだが、台本外の発言を使う場合はこの基準で判断し、迷ったら使わない。
3. 1人の発言が90秒を超える場合は、インサート（写真・図解）を挟む。
4. ジャンプカットは、話者が替わるタイミングか、インサートの裏で行う。どうしても同一話者内で切る場合は、1.1〜1.2倍のデジタルズームで切り替える。
5. 言い淀み、「えー」「あの」は切ってよいが、方言や言い回しは残す。整えすぎない。
6. 聞き手の声は原則使わない。質問は「質問テロップ」（下記5.4）で画面に出す。

## 5. テロップ仕様

### 5.1 共通

| 項目 | 指定 |
|---|---|
| フォント | Noto Sans JP（Bold / Black）。見出しは Black、本文は Bold |
| 文字色 | 白。縁取り：濃紺（#1F2A44）2〜3px。または半透明の帯（黒 60%）の上に白文字 |
| ブランド色 | 【要確認：当法人のロゴ色。未定なら 濃紺 #1F2A44 ＋ アクセント 山吹 #E8B339】 |
| 配置 | 画面下 1/4。名前テロップは左下 |
| 表示時間 | 1行あたり 2.5 秒以上。読み切れる長さを優先 |
| 1画面の文字数 | 要点テロップ 20字以内。全文字幕 2行×18字以内 |

### 5.2 要点テロップ（キーワード）

- 発言のすべてを文字にしない。発言中の結論、数字、固有名詞、言い切りだけを大きく出す。
- 数字と固有名詞（地名、団体名、制度名、年）は必ずテロップにする。表記は構成台本の「テロップ文言」列に従う。表記が台本にない固有名詞は担当に確認する。
- 強調は色変え（アクセント色）か文字サイズ 1.3倍。アニメーションは「フェード」か「ポップ 0.2秒」のみ。

### 5.3 全文字幕

- 聞き取りにくい箇所（構成台本で「全文字幕」と指定した区間）のみ、2行×18字以内の全文字幕を入れる。
- 位置は画面下、要点テロップと重ねない（要点テロップを出す間は全文字幕を上に逃がす）。

### 5.4 質問テロップ

- 聞き手の質問を画面上部または中央に、角丸の帯で表示。例：「Q. 学生が来る前、地区はどんな状況でしたか？」
- 表示は 3〜4 秒。出演者が答え始めたら消す。

### 5.5 名前テロップ

- 初登場時と、各章の最初の登場時に表示。4秒。
- 表記：「木戸 隆一郎｜洲本市議会議員」「竹本 ○○｜【要確認】」。肩書は担当が確定した文字列をそのまま使い、編集者側で略したり補ったりしない。

### 5.6 章カード

- 各章の頭に 3 秒。黒または濃紺の背景に、章番号と章題（疑問形）。例：「③ 受け入れの段取りと、つまずいたこと」
- 章カードの間に 0.5 秒の無音を入れてよい。

### 5.7 冒頭ハイライト

- 構成台本の「ハイライト」区間を 3〜5 カット、合計 30〜60 秒。
- 各カットに要点テロップ（大きめ、画面中央寄り）。
- 最後の 1 カット後に 1 秒の黒、問いテロップ（例：「学生が来ると、地域は本当に変わるのか？」）を 3 秒、続けてタイトル。

## 7. 音声・BGM

- ノイズ除去、音量の均一化を行う。声が不自然に加工されたように聞こえるレベルまで処理しない。
- BGMは冒頭ハイライト、章カード、エンディングのみ。本編の会話中は無音か、聞こえるか聞こえないか程度（-30 dB 以下）。
- BGMはライセンスが明確なものだけ。YouTubeオーディオライブラリ、DOVA-SYNDROME、または編集者が権利を持つ楽曲。曲名・出典・ライセンス条件を納品時に一覧で提出。
- 効果音は章カードの切り替えに控えめな1種のみ。

## 8. ショート3本

構成台本の「ショート候補」から3本。方針は `05_YouTube公開テキスト案.md` の「ショート」節にある。

- 縦型。出演者の顔を中央に、上部に見出しテロップ（14字以内）、下部に全文字幕。
- 冒頭 2 秒以内に最も強い言葉を置く。本編の順番通りである必要はない。
- 末尾 3 秒に「本編はプロフィールのリンクから」のテロップ。
