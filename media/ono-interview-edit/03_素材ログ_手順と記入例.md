# 素材ログの取り方（手順と記入例）

対象：https://youtu.be/2-AvwIqPyfY（動画ID：2-AvwIqPyfY）、https://youtu.be/a24NbWjA8X4（動画ID：a24NbWjA8X4）
所要：2本で2〜3時間（1人）。2人で1本ずつ分担すれば1時間半。
使うもの：`03_素材ログシート.csv`（Googleスプレッドシートに取り込む）、YouTube Studio、ヘッドホン。

この作業の目的は、2本の動画を「発言」という単位に分解し、どの発言をどの章で使うか、何をテロップにするか、何を確認するかを一覧にすること。編集者には構成台本とこのログを渡す。ログがあれば、編集を誰に頼んでも同じ結果になる。

---

## 手順

### 1. 自動字幕を落とす（10分）

1. YouTube Studio → コンテンツ → 対象の動画 → 字幕。
2. 「日本語（自動）」の右のメニューから「ダウンロード」→ 形式は .srt。
3. 2本分を Drive「メディア事業／大野地区インタビュー／ログ」に保存。ファイル名は `2-AvwIqPyfY_auto.srt` のように動画IDを付ける。

自動字幕が出ていない場合（限定公開でも通常は生成される）、Vrew に動画URLまたはファイルを読み込ませて書き出す。

### 2. 発言単位に切る（本作業）

.srt を見ながら動画を再生し、「1つの問いに対する1つの答え」を1行にする。目安は30秒〜2分。話題が変わったら行を分ける。

記入するのは以下の列。

| 列 | 書き方 |
|---|---|
| 動画ID | `2-AvwIqPyfY` または `a24NbWjA8X4` |
| 開始 | `mm:ss`（例：`03:12`） |
| 終了 | `mm:ss` |
| 話者 | `木戸` / `竹本` / `聞き手` / `その他` |
| 問い | 聞き手の質問を一言で。質問がなければ話題を書く |
| 発言要約 | 2〜3文。出演者の言葉遣いを残す。「〜と語る」のような第三者文体にしない |
| キーフレーズ | そのままテロップにできる言い切り。1つ。原文のまま（例：「最初は正直、面倒やなと思った」） |
| 数字・固有名詞 | 発言に出てきた数字、地名、団体名、制度名、人名。聞き取りに自信がなければ末尾に `?` |
| 章候補 | `1` / `2` / `3` / `4` / `ハイライト` / `エンディング` / `なし`。複数可（`2,ハイライト`）。章の定義は `01_編集企画書.md` の3.2 |
| 評価 | `A` 必ず使う / `B` 尺が許せば使う / `C` 使わない |
| ショート候補 | `Y` なら縦型ショートで単体で成立する発言。理由を備考に |
| 政治 | 市政批判、政策主張、議員・会派・政党・選挙・公約への言及があれば `Y`。評価は自動的に `C` |
| 第三者 | 第三者の個人名や、映像に第三者の顔が映っていれば `Y` |
| 要確認 | 出演者か市企画課に確認が要ることを書く（固有名詞の表記、数字の正確さ、公開可否） |
| 備考 | 音声の状態（風音、反響）、映像の状態（手ブレ、逆光）、インサートで隠したい箇所など |

### 3. 評価の基準

| 評価 | 基準 |
|---|---|
| A | 具体的なエピソード、数字、固有名詞、言い切りのどれかがあり、第1〜4章のどれかに当たる |
| B | 内容は良いが抽象的。または他の発言と重複 |
| C | 雑談、言い淀みだけ、政治タグ、聞き取れない、本題から外れる |

迷ったら B。A は1本あたり10〜15発言に絞る。

### 4. 集計（10分）

ログが終わったら、スプレッドシートの末尾に次の3行を作る。

- 評価Aの合計尺（分）：この数字で1本か前後編かを決める（12分未満→短い1本、12〜25分→1本、25分以上→前後編）
- 章ごとのA＋Bの発言数：0の章は削る
- 「要確認」の件数：出演者確認の依頼文（`06`）に転記する

### 5. 提出

Googleスプレッドシートの共有リンクを鈴木に送る。件名は「大野インタビュー 素材ログ 完了」。本文に「評価A合計尺」「章ごとの発言数」「要確認の件数」の3つを書く。

## よくある迷い

- **発言が長くて1行に収まらない**：話題が変わるところで分ける。同じ話題なら2分を超えても1行でよい。
- **聞き手の質問が聞こえない**：答えから逆算して「問い」を書く。質問テロップの文言はあとで鈴木が決める。
- **自動字幕が固有名詞を誤認識している**：キーフレーズは聞いた通りに直す。自信がなければ `?` を付けて要確認に回す。直せないまま放置しない。
- **同じ話が2本の動画で重複している**：両方ログに残し、備考に「○○と重複」と書く。どちらを使うかは構成段階で決める。
