# 科研費構想：EU構造基金「目標6」——配分基準の選択と硬直性

> 着想メモ（2026-08-23）：「科研費、object6の形成過程で出す方が面白いかも！ 国際関係論と財政学の架け橋」
> 方針決定（2026-08-25）：**このテーマに乗り換え。応募区分は 07050「財政および公共経済関連」。**

## 前提の確認

**object6 = EU構造基金の「目標6（Objective 6）」**。1995年の北欧拡大（フィンランド・スウェーデン加盟）
に際し、加盟条約議定書第6号によって創設され、**人口密度8人/km²未満のNUTS2地域**を対象とした移転枠です。
違っていたら最初に言ってください。

## 応募区分の判断：07050（財政および公共経済関連）

応募者の業績が財政学中心であることを踏まえた決定です。06020（国際関係論関連）では、
審査委員が業績を評価する土俵を持たず、「EU研究の実績がないのに一次史料調査ができるのか」
と読まれる二重の不利になります。

**区分を変えたので、構想の向きも変えてあります。** 番号を書き換えるだけでは通りません。

| | 06020版（不採用） | **07050版（これで書く）** |
|---|---|---|
| 問い | 交渉の産物がなぜ恒久制度になるか | **移転基準はどう選ばれ、なぜ改定されないか** |
| 財政学の役割 | 分析の道具 | **問いと規範的含意の本体** |
| 国際関係論の役割 | 本体 | **「なぜその基準が選ばれたか」を説明するメカニズム** |
| 中核の方法 | 一次史料・過程追跡 | **閾値シミュレーション・基準の陳腐化の定量化** |

財政学が問いを立て、国際関係論が答えを供給する——この順番なら 07050 の審査委員に自然に読めます。

## この案の一行要約

**「金額は毎期の交渉で削られてきた。閾値は30年間、一度も改定されていない。」**

目標6というカテゴリー自体は1999年のアジェンダ2000で目標1に統合され消滅しましたが、
8人/km²という閾値は生き残り、2009年のリスボン条約でEU運営条約第174条に書き込まれました。
この非対称性が、財政移転の基準設計を考えるための素材になります。

## 07050で通すために外せない3点

1. **Q3（帰結）を必ず書く。** Q1（なぜその基準か）とQ2（なぜ変わらないか）だけでは制度史で終わります。
   基準が固定されたまま人口動態が動くことで配分にどんな歪みが出るか——ここが財政学の研究にする条件。
2. **日本への含意を前半に置く。** 審査委員は必ず「なぜEUの話を？」と考えます。
   答えは「日本では指標選択の過程が文書で追えないが、EUなら追えるから」。先に示す。
3. **RDDを約束しない。** NUTS2の観測数も閾値近傍の地域数も少なく、因果推定は成立しません。
   「記述的な不連続性の提示と境界事例の質的分析」と正直に書く。無理な手法を書くほうが減点されます。
