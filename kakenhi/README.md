## 結論：v3 を本命とし、形成過程は「識別の防御」として組み込む

Drive の `研究計画調書_S-14_基盤C_鈴木伸_v3.pdf`（2026-08-16）を全文確認した結果、
**当初検討していた「目標6の形成過程」への全面的な乗り換えは勧めない。**

### なぜ v3 の方が強いか

| v3 が持つもの | 形成過程版だと |
|---|---|
| フィンランド自治体財政パネル **462自治体×22年**（スタート支援で構築済み） | これを使わず、NUTS2の人口密度DBをゼロから構築することになる |
| **『財政研究』掲載決定論文**が2仮説の典拠（2026年6月、査読有） | 掲載決定論文が「基盤」ではなく「代替物」の位置になる |
| **縮退設計**（データ制約下でも成立する到達点を事前定義） | 一次史料の公開状況に成否が依存する |
| 追加性・fungibility・フライペーパー効果＝07050の中心的関心 | 制度史寄りになり、財政学の土俵から外れるリスク |

区分の判断（**07050 財政および公共経済関連**）自体は正しい。v3 はすでにその土俵で書かれている。

### 形成過程の正しい使い道

v3 の識別は「目標6指定＝処置」に依存する。ここに反論の余地がある——
**指定基準（8人/km²）が交渉で受益地域に合わせて逆算されたものなら、処置割当は外生ではない。**

したがって形成過程の解明は、v3 の代替ではなく**識別の前提の防衛**として機能する。

- 閾値が既存の人口密度データに機械的に適用された → 外生性の積極的根拠になる
- 交渉で受益自治体に合わせて逆算された → その事実を明示し、境界の扱いと感応度分析で対処する

どちらに転んでも v3 は強くなる。→ 具体的な差分は [`03-v3-integration.md`](03-v3-integration.md)
