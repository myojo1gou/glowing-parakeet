# 科研費構想：EU構造基金「目標6」の形成過程

> 着想メモ（2026-08-23）：「科研費、object6の形成過程で出す方が面白いかも！ 国際関係論と財政学の架け橋」

## 前提の確認（最初に読んでください）

この一式は **object6 = EU構造基金の「目標6（Objective 6）」** という前提で組んでいます。
1995年の北欧拡大（フィンランド・スウェーデン加盟）に際し、加盟条約議定書第6号によって創設され、
**人口密度 8人/km² 未満の NUTS2 地域** を対象とした、それまで存在しなかった構造基金の目標です。

**前提が違っていたら、まずそれだけ教えてください**（例：SDGs目標6＝水・衛生 の話であれば全面的に組み直します）。
以下の内容は、この前提が正しい場合にのみ意味を持ちます。

## この案の一行要約

**「国家間交渉のサイドペイメントが、金額ではなく〈基準〉の形をとったために、交渉が終わっても生き延び、
最終的に条約本文（TFEU 174条）にまで到達した」** ——その30年間を一次史料で追う研究。

国際関係論（交渉・拡大・サイドペイメント）と財政学（政府間財政移転のニーズ指標設計）は、
この一点で必然的に交差します。「架け橋」が修辞ではなく事例に内在しているのが、この案の強みです。

  **応募締切 2026年9月17日(木)16:30**。

## 判断が要る論点（こちらで仮置きしている）

1. **種目**：基盤研究(C)（3〜5年・総額400万円以内）を既定として書いています。若手研究の要件に該当するか、
   あるいは基盤(B)規模にするかで、年次計画と経費は差し替えが必要です。
2. **審査区分**：小区分 **06020 国際関係論関連** を本命、**07050 財政および公共経済関連** を対抗として想定。
   → `01-concept.md` の「9. 科研費戦略」に、どちらを選ぶかで書き分けるべき点をまとめています。
3. 「架け橋」は**諸刃の剣**です。両分野に等距離で書くと両方の審査委員から「自分の分野ではない」と見られます。
   応募区分を決め打ちし、その分野の評価軸で書き、もう一方は「波及効果」として置くのが定石です。
