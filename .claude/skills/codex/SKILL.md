# Codex 連携スキル

Codex CLI（`codex exec`）を非対話で呼び、別モデルの意見や作業結果を受け取る。Codex の出力は**そのまま採用しない**。Claude が読み、事実確認し、採否を判断してからユーザーに返す。

## 使い分け

| 場面 | Codex に渡すもの | サンドボックス |
|---|---|---|
| コード変更のレビュー | `git diff` と変更意図 | read-only（既定） |
| 研究計画・論文草稿への査読者コメント | 草稿ファイルのパスと、見てほしい論点 | read-only |
| 事業計画・予算の穴探し | 計画書のパスと、前提条件 | read-only |
| 独立した実装案を作らせて比較 | 仕様と対象ファイル | `-w`（workspace-write） |
| 単純作業の委任（テスト追加、整形など） | 具体的な完了条件 | `-w` |

書き込みを伴う委任は、ユーザーが明示的に頼んだときだけ行う。レビュー・意見聴取は read-only で十分。

## 手順

1. **前提確認**: `command -v codex` で存在を確認。なければ「`npm i -g @openai/codex` と `codex login`（または `OPENAI_API_KEY`）が必要」とユーザーに伝えて止まる。勝手にインストールしない。
2. **プロンプトを組む**: Codex はこの会話を見ていない。下のテンプレートで、目的・対象ファイル・判断基準・出力形式を全部書く。Claude 自身の結論は書かない（アンカリングを避けるため）。
3. **実行**:
   ```bash
   .claude/skills/codex/scripts/ask_codex.sh [-w] [-m MODEL] [-C DIR] <<'PROMPT'
   （プロンプト本文）
   PROMPT
   ```
   最終回答は `.codex-out/<日時>.md`、実行ログは同名 `.log` に残る。追加質問は `--resume` で同じセッションに続ける。時間がかかるので Bash の timeout は 600000 を指定する。
4. **検証**: 指摘ごとに該当箇所を実際に読み、「妥当／誤り／判断保留」に分ける。Codex がファイルを書き換えた場合は `git diff` で全差分を確認する。
5. **報告**: ユーザーには次の形で返す。
   - 結論（採用すべき指摘の数と最重要点）
   - 指摘一覧（妥当／誤り／保留、根拠つき）
   - Claude と Codex で見解が割れた点
   - 次にやること

## プロンプトテンプレート

### コードレビュー
```
あなたはこのリポジトリのレビュアーです。以下の変更をレビューしてください。
目的: <変更で何を実現したいか>
対象: `git diff main...HEAD` を自分で実行して確認すること
観点: バグ、境界値、エラー処理、セキュリティ、既存コードとの不整合
出力: 指摘ごとに「ファイル:行／問題／再現条件／修正案／重大度(高中低)」。問題がなければ「指摘なし」とだけ書く。推測の指摘には「推測」と明記。
```

### 査読者コメント（研究）
```
あなたは公共財政・地域政策分野の査読付き学術誌の査読者です。
対象: <ファイルパス>
見てほしい点: 研究の問いの新規性、先行研究上の位置づけ、データと識別戦略、反証可能性、結論の飛躍
出力: (1) 判定（accept/minor/major/reject）と理由3行 (2) 主要コメント (3) 細部コメント (4) 著者が追加すべき分析・データ。褒め言葉は不要。
```

### 事業計画の穴探し
```
あなたは NPO の事業計画を審査する財団担当者兼会計士です。
対象: <ファイルパス>
確認点: 価格と原価、人件費の積算、担当者の実在性、契約・請求・証憑の流れ、収支が赤字化する条件、代表者への業務集中
出力: リスク一覧（内容／発生条件／影響額の目安／対策）と、計画書に追記すべき項目。
```

## 注意

- 個人情報・未公開データ・契約書の実物を渡すときは、OpenAI 側に送信されることをユーザーに確認してから。
- Codex の回答に含まれる文献・制度名・数字は Claude が裏取りするまで事実扱いしない。
- `.codex-out/` は `.gitignore` 済み。成果物として残したいものは別ファイルにまとめ直す。
- クラウドセッションでは codex 未導入・api.openai.com 未許可のことが多い。その場合は環境設定（ネットワーク許可と API キー）が必要と伝える。
