# 2026/8/23 オープンキャンパス 学科紹介スライド（改訂版）

福山大学 経済学部 国際経済学科の学科紹介スライドを、
**高校生・保護者が退屈せずに聞ける／会場の後方でも読める** ように作り直したものです。

## 成果物

| ファイル | 中身 |
|---|---|
| `01_学科紹介_8月23日OC_鈴木版_改.pptx` | **本体**。26枚・16:9・全スライドに発表者ノート付き |
| `変更点まとめ.md` | 何をどう変えたか、その根拠。まずこれを読んでください |
| `進行表.md` | 時間配分表と、押したときに削る順番 |
| `写真の差し込み一覧.md` | どのスライドにどの写真を入れるか |
| `想定質問と回答.md` | 保護者・高校生からの質問への返し方（答えてはいけない項目つき） |

## 作り直す／直すとき

```bash
pip install python-pptx
python3 content.py spec.json                    # 本文と発表者ノート -> spec.json
python3 build.py spec.json 出力.pptx             # spec.json -> pptx（可読性チェック付き）
./render.sh 出力.pptx                            # 目視確認用に PNG を書き出す（要 LibreOffice）
```

本文を書き換えるのは `content.py` だけです。
`build.py` は **16pt未満の文字・24pt未満の本文・5項目以上の箇条書き・枠からのはみ出し**
を見つけるとビルドを止めます。「文字が小さい」状態に戻らないための仕組みです。

| ファイル | 役割 |
|---|---|
| `content.py` | スライド本文と発表者ノート（ここだけ編集すればよい） |
| `deckkit.py` | 文字サイズ・色・余白の設計と、可読性の検査 |
| `layouts.py` | 13種類のレイアウト実装 |
| `build.py` / `render.sh` / `make_docs.py` | ビルド・プレビュー・付属ドキュメント生成 |
| `src/` | 元スライドから抽出した素材（A=7月OC版、B=8/19上下高校版） |
