## 1. 「文字が小さい」への対処 ― 装飾ではなく情報量の問題として解いた

文字を大きくできない原因は、1枚に載せている情報が多すぎることです。
そこで**文字サイズの下限を先に決め、そこに入らない文章を削る**という順序で作り直しました。

| 用途 | 改訂版 | 目安 |
|---|---:|---|
| 見出し | **44pt** | 1行20字以内 |
| リード文 | **30pt** | 1行25字以内 |
| 本文・箇条書き | **28pt**（下限24pt） | 1行27字以内・**最大4項目** |
| カード内・階段図 | 24pt（下限20pt） | 幅が狭い枠のみ |
| 注記・出典 | **18pt**（下限16pt） | 1〜2行 |
| 巨大数字 | 150pt | 95万円・45.5%・8人 |

根拠：最後列15m・投影高1.5mの会場で漢字1字が判読できる下限から逆算しています
（1字の高さ ≧ 距離/150）。「見出し40pt台・本文28pt」は盛った値ではなく最低ラインです。

あわせて、次を機械的な制約としてビルドに組み込みました。
**16pt未満の文字・24pt未満の本文・5項目以上の箇条書き・枠からのはみ出しがあると、ファイルが出力されません。**
今後この資料を編集しても「文字が小さい」状態には戻りません（`build.py` が止めます）。

### 表を3つとも廃止しました
会場で最も読めないのが表です。元の3つの表を、次の形に置き換えています。

- 教員8名×4列の表 → 巨大数字「8人」＋出身機関・言語の3項目（9枚目）
- 資格・検定 5行の表 → 出願要件2つ＋在学中の目標1つ（23枚目）
- 海外プログラム 5行の表 → Big Jumpの階段図に集約（11枚目）

氏名・専門分野の一覧は配布チラシ側に寄せる想定です（口頭で「チラシに載っています」と誘導）。

### 色のコントラストも作り直しました
白地に金色（1.9:1）など、投影すると消える組み合わせを排除し、
本文は7:1以上、大きな太字でも4.5:1以上を確保しています。金色は「面」だけに使い、文字には使っていません。

### 下端に重要な情報を置かないようにしました
前列の頭・演台・スクリーン下端の暗幕で、画面の下15%は多くの席から見えません。
本文は上0.55inch〜下1.05inchの安全域に収め、注記もその内側に入れています。

## 2. 「退屈させない」への対処 ― 3山2谷の設計にした

均一な強さで26枚続けると、高校生は中盤で必ず落ちます。起伏をスライド番号に固定しました。

| 位置 | 役割 | 枚 |
|---|---|---|
| 山① 5分 | 経済学クイズ（会場が最初に体を動かす） | 5〜6 |
| 谷① 7〜9分 | 学科の説明。短く走り抜ける | 7〜9 |
| 山② **12分**（最大） | **95万円** の巨大数字。全体の約6割地点 | 16 |
| 谷② 15分 | 「英語が苦手でも大丈夫」。ここで拾い直す | 18 |
| 山③ 19分 | 入試「語学の条件をもう満たしています」 | 24 |
| 収束 | まとめ → キャンパスへ | 25〜26 |

### 具体的に入れた仕掛け

1. **伏線を2本にしました。**
   - 表紙のNZ写真 →（14枚目）「最初にお見せした写真、覚えていますか」で回収
   - アジェンダの「今日、数字を1つだけ覚えて帰ってください。何の数字かは②で言います」
     →（16枚目）「これが、さっき言った数字です」で回収
2. **挙手を3回とります。** アイスブレイク（2枚目）／経済学クイズ（5枚目）／入試（24枚目）。
   開始5分までに一度も体を動かさない講演は、最後まで受け身になります。
3. **通常スライド3枚に1枚は変化球を挟みました。** 区切り3枚・写真2枚・巨大数字2枚・問いかけ2枚。
4. **黄色い帯**は「口に出して言う一文」です。読み上げるだけで場が動くように書いてあります。
5. **区切りスライドを3枚**入れて、話の切れ目を体で分かるようにしました。

### 高校生向けと保護者向けを1枚の中で分けました
見出しと箇条書きは生徒向け、注記と発表者ノートは保護者向けです。
保護者に効く材料（留学中の就活オンライン個別指導・修了証・自宅通学の費用）は
ノートに「ここは保護者席のほうを向いて言ってください」と明記しています。

## 3. 表現の修正 ― 対外資料としてのリスクを取り除いた

保護者に「うちの子も必ずもらえる・必ず入れる」と読ませてしまう書き方を、
魅力を落とさずに直しました。**ここは元のままだと質疑で事故になり得る箇所です。**

| 元の表現 | 改訂版 | 理由 |
|---|---|---|
| 「最大95万円」の巨大表示単独 | 95万円＋**同じ画面に3段の内訳と条件**（1年3万は条件あり／2年30万・3年62万は選抜10名程度） | 単純合算値。1人が3つ全部を受けられるとは素材のどこにも書かれていない |
| 「決して狭き門ではありません」 | 「1学年の定員は40名。研修・留学の枠はそれぞれ10名程度です」（事実の並置） | 倍率・選抜基準の根拠がなく、選ばれなかった場合にクレーム化しうる |
| 検定料補助「全員対象」 | 「学科の全員が対象ですが、支給には英検準2級レベルの取得などの条件があります」 | 元のノートに条件の記載があり、本文と食い違っていた |
| 「もう出願資格があります」 | 「語学の条件をもう満たしています」 | 指定校推薦は高校が指定を受けていることが前提。OCは不特定多数の高校生が来る |
| 「授業料半額免除」が2か所 | 留学側＝「留学中の授業料 半額相当42万円を免除」／入試側＝「入学後の授業料を半額免除」 | 別制度なのに同じ言葉で、二重に半額になると誤読される |
| 「卒業後の進路」 | 「こんな道に進めます」 | 具体的な就職先が未確認。実績語で書くと列挙した業界を実績と読まれる |
| 教員の「出身者」 | 「勤務経験を持つ教員がいます」＋「2026年8月時点」 | 在籍形態が特定できず、経歴を強めに読ませる |
| 満足度グラフに税務会計学科10.5% | **削除**（国際経済/経済学科/全学平均の3本に） | 同じ日に説明会を開いている学科を並べて低く見せない配慮 |

出典表記も2種類に固定し、注記は「スライドに残す／ノートに送る／口頭でだけ言う」で振り分けています。

## 4. 構成の変更点（元との対応）

- **教員紹介を前半から後ろへ**（9枚目）。開始3分に一覧表を置くのが最大の離脱点でした。
- **上下高校版の「府中市・上下町」の枠**は、OCでは使えないので
  **「経済学クイズ →『世界と地域はつながっている』」**に差し替え。会場の全員に等しく効きます。
- **経済学の定義を、宣言からクイズに**（5〜6枚目）。「お金もうけではありません」と一度否定してから定義に入ります。
- **アジェンダを新設**（3枚目）。7月OC版にはありませんでした。「あと何分続くか」が読めないと集中が切れます。
- **お金の話を独立した山場に**（16枚目）。
- **アイスブレイクと自己紹介（あげ太くん）は残しました。** OCの空気づくりに効きます。
- 旧版の「全員立ってください」ゲーム（3分）はOC版では採用していません。20分の15%を食うため、
  5枚目の挙手クイズ45秒に置き換えました。ゲームを使う場合は5〜6枚目と差し替えてください。

## 5. 使うときの手順

1. **写真を差し込む**（`写真の差し込み一覧.md` 参照）。表紙とTOP10の2枚は伏線なので必ず。
2. **フォント**は Meiryo で作ってあります。より読みやすくするなら
   ホーム → 置換 → **フォントの置換** で `Meiryo` → `BIZ UDPゴシック` に一括変更してください。
3. **発表者ノート**に、話し方・間の取り方・言ってはいけないことまで書いてあります。
   印刷するなら「ノート」レイアウトで。
4. **持ち時間に合わせて削る**（`進行表.md` の削る順番）。
5. **答えられない質問**への返し方は `想定質問と回答.md` に定型文があります。
